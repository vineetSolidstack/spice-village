# Customer App UI Kit
Mobile PWA (390px), click-through: Home (browse kitchens, cuisine filters) → Kitchen storefront (menu/combos, cart stepper) → Cart (savings callout) → Place order → Orders with QR pickup code. Workshops tab: list → detail (session, participants, pay at venue/online) → booking confirmation. Profile: account rows + trilingual LanguagePicker (switching language re-renders nav + key strings in Tamil/Hindi).
Files: `customer-data.jsx` (Lucide inline icons, i18n strings, demo data, QR placeholder), `customer-screens.jsx` (screens + app shell), `index.html`.
All primitives come from the design-system bundle — no re-implemented components. Food photos are gradient placeholders pending real photography.
